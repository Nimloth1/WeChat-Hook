# 图片只在原图核验通过后入队

PM 转发器保留源事件的 `image_info`，选图时要求解码字节数等于
`original_bytes`，且消息中已知的宽、高分别一致。源消息没有字节数但提供完整宽高时，
要求两维完全匹配，并验证PNG块完整性或JPEG结束标记；不展开像素，不降级成小图。
这种情况只能确认原始尺寸的完整文件，不能声称完成了原发送方文件的字节级核验。
候选名称或 `_h` 后缀不构成原图证明。此检查只改变 PM 选图，不改变附件传输、VW12 执行器、
DLL、逐条许可或目标群。

预览先落盘时保持 `media.waiting`；每轮原有的有界轮转会再检查，原图出现后
才生成固定摘要的发送任务。缺少字节数且宽高也不齐全、元数据无效或候选不匹配时保持等待，
不会静默降级。等待不阻塞后续文字或其他已就绪附件；超过24小时仍沿用既有
`attachment_expired_requires_review` 暂停/告警规则，本补丁不改变该规则。

V2 文件从封装头及长度即可计算明文长度，大小不匹配的候选不解码落盘。
尺寸错误或结束标记/PNG完整性错误的候选只临时解码一次，立即清理；后续轮询用内存中的
文件签名及预期元数据跳过，文件或预期信息变化后重新检查。重启后重新核验一次。
没有新增轮询写盘、截图、下载器、窗口操作或发送重试。

部署前须核对旧待处理队列。旧图片索引未保留 `image_info`，不能擅自当作原图；
本次部署现场旧 `waiting` 和待发任务均为0，无须迁移索引或重放历史。
历史已发图片及其消费标记保持原样；补发须另有用户授权。

验证：

```sh
python -B -m unittest discover -s tests -p 'test*relay*.py'
```

`tests/test_relay_original_images.py` 使用真实合成 V2 文件和临时账本，覆盖
预览先到/原图后到、候选顺序、大小错误、相同大小但尺寸错误、元数据缺失或无效、
可选尺寸、文件更新后重检及无变化不写入。该测试不连接微信或真实发送。
