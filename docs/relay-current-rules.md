# 当前转发范围和仍生效的规则

用户已要求同一来源群所有成员都转发。两端 policy 的 `corporations: null`
显式表示不按机构或成员过滤，包括无机构信息的个人和来源账号本人；
旧的非空列表仍兼容原来的受限模式。该配置必须在 PM 和 VW12 同步。
文字只对实际国泰君安使用 gtja/gtja sg 简称，其他机构保留机构名称，
无机构只显示发送人，不再把所有人标成 gtja。

本次部署保留原 cursor、activated_at、任务、消费标记和目标，只更新已授权的
机构策略摘要，继续从原水位消费。之前已被过滤的记录不会回放；不重建 baseline。
不需要更换 DLL 或重开微信。

## 业务行为

| 项目 | 当前行为 |
|---|---|
| 来源/目标 | 固定已配置来源群 → 固定目标群；不转发其他群 |
| 成员 | 所有成员，包括其他机构、普通个人、本人 |
| 类型 | 文字、图片、普通文件（含音频文件）、聊天内视频；链接以标题＋网址普通文字转发 |
| 未实现的类型 | 表情、原生语音气泡、名片、小程序、合并聊天、系统消息等不转发；没有把它们当作已支持 |
| 图片 | 有原图长度时按长度及已知宽高核验；只有完整宽高时匹配原尺寸并检查文件完整性；不发送小尺寸预览替代 |
| 发送间隔 | 默认无固定间隔；可按用户要求临时配置节奏，补发结束后取消，等待期间不claim、不消耗许可 |
| 数量配额 | 无每日消息数或每日附件字节配额 |
| 单条业务大小 | 已取消旧2000字、20MiB等门槛；仍受下面的协议/资源边界约束 |
| 旧消息 | 基线前、已消费消息不补发；源事件超过24小时或时间在未来会跳过 |
| 已入队过期 | 待发送任务或等待附件超过24小时，仍会暂停整条链路并告警；本次未改变 |
| 异常结果 | 超时、未知结果或预检/执行失败会暂停，不自动重试 |
| 许可 | 每条绑定目标、内容、模块及请求ID；v2没有时间到期，但仍防重放 |
| 登录 | 不自动登录/扫码/重启；现有观察任务定期提醒登录提示或无法观察 |

## 协议和资源边界

2026-11-03 首条自动原生链接卡片调用后微信发生执行访问异常，两端暂停。
用户授权恢复及补发暂停期间未处理消息。自动采集现在将链接原文转为带发送人的
普通文字，不再生成新的原生卡片任务；不会打开或请求该网址。原生卡片接口留待
离线查修，不能将普通文字降级视为原生卡片已修好。

已存在旧卡片任务时，按原始 link ID 阻止因改用 text ID 而重新发送同一来源消息。
崩溃任务保留全部原证据，运维结案为 `closed_unknown_no_retry`，既不标成功，也不标
未发送；client/used标记保留，不再尝试。解除该次暂停继续原水位，不清空账本或重建
baseline；补发只覆盖暂停期间未处理消息。图片缺少字节数但有完整宽高的情况现已
补充原尺寸/文件完整性核验；缺少足够元数据仍等待，不静默降级成预览。

以下都不是微信账号风控阈值，也不是限速策略：控制 JSON 及 DLL HTTP 体16MiB、
源 JSONL 单行1MiB；待发描述符约100MiB、账本约200MiB及附件索引50000条检查；
磁盘至少保留1GiB并按本次写入再检查。达到这些条件会报错/暂停，不会悄悄缩小图片。
SSH控制90秒、附件上传900秒、DLL HTTP20秒、原生资源回收40秒仍有超时。

文件名180字符、卡片标题256/摘要2000/URL2048个UTF16单元、HTTP(S)链接、
MP4及JPG封面格式、视频时长不超过24小时等沿用现有协议。没有在本次取消这些
ABI/协议约束，且尚不能用原生调用成功替代接收端送达确认。

## 验证

离线回归覆盖受限/全部成员策略、无机构资料、其他机构、本人消息、前缀准确性、
五种类型在来宾执行器内通过、错误目标仍拒绝、同一任务不重试，以及切换策略时
保留原水位不回放已过滤记录。生产部署只改变两端脚本与机构策略，不触碰登录、
DLL、VW11或历史消息。
